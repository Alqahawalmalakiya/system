تحديث جدول المناسبات وحذف الفواتير

فك الضغط وارفع مجلدي app وlib الموجودين في هذه الحزمة إلى جذر مستودع GitHub نفسه Alqahawalmalakiya/system باستخدام Add file > Upload files ثم Commit changes. هذه الملفات تستبدل أربعة ملفات فقط، ولا تعدل worker.ts أو wrangler.json أو إعدادات الدخول أو معرّف قاعدة البيانات. لا تحذف المجلدات الحالية.

انتظر نجاح البناء على Cloudflare وحدّث صفحة النظام.

المناسبة التي اختير لها تمت المناسبة أو مر تاريخها بتوقيت جدة تظهر بالرمادي وكلمة انتهت. مناسبة اليوم التي لم تكتمل ولم تُلغ تظهر بالأخضر وكلمة اليوم. الملغاة تبقى ملغاة. تصنيف اللون لا يغير الدفعات أو حالة الحجز المالية تلقائيًا. قسم الحجوزات يفتح على كل الحجوزات افتراضيًا لتظهر المنتهية أيضًا.

للحذف افتح تفاصيل الفاتورة واضغط حذف الفاتورة، ثم اقرأ رسالة التأكيد. الحذف نهائي ويزيل الحجز والدفعات المرتبطة به؛ صدّر نسخة احتياطية قبل حذف ما قد تحتاجه. أرقام الفواتير المحذوفة لا تُعاد إلى فواتير جديدة.

تم التحقق من TypeScript والبناء ومن تصنيف الحالات ومن تحقق واجهة الحذف من الهوية ومصدر الطلب والمعرّف وحالة عدم وجود الفاتورة. لم تُنشر هذه الحزمة تلقائيًا على مستودع العميل ولم يتم اختبارها بصريًا على الموقع الخارجي.
