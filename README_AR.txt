تحديث مشاركة ملف PDF والفاتورة

فك الضغط وارفع مجلدي app وlib إلى جذر نفس مستودع GitHub باستخدام Add file > Upload files ثم Commit changes. لا ترفع مجلدًا إضافيًا فوقهما ولا تحذف المجلدات الحالية. انتظر نجاح آخر بناء Cloudflare ثم حدّث النظام بالكامل.

الحزمة تشمل التعديل السابق لألوان المناسبات والحذف أيضًا لضمان اكتمال الملفات المرتبطة. لا تغير worker.ts أو wrangler.json أو قاعدة البيانات.

إرسال PDF: اضغط تجهيز PDF للمشاركة داخل الفاتورة، ثم إرسال PDF واختر واتساب. بعد حفظ PDF يكون الملف جاهزًا للإرسال أيضًا. نافذة مشاركة الملفات تستقبل ملف application/pdf فقط ولا تستقبل عنوان الموقع أو رابطًا أو رسالة نصية. إذا كان المتصفح لا يدعم مشاركة PDF، يتم تنزيل الملف لإرفاقه يدويًا في واتساب. زر رسالة واتساب منفصل ويرسل تفاصيل الفاتورة نصيًا.

أزيلت عبارة جميع المواعيد بتوقيت جدة من داخل الفاتورة وشكل PDF. الحساب الداخلي للمواعيد يبقى بتوقيت جدة.

تم التحقق من TypeScript والبناء ومن توليد PDF فعلي ومشاركة ملفات فقط ومن التعامل مع إلغاء المشاركة وتنزيل الملف عند عدم الدعم. لم يتم إرسال فاتورة إلى شخص أو اختبار تطبيق واتساب على جوال فعلي، ولم تنشر الحزمة تلقائيًا على GitHub أو Cloudflare.
