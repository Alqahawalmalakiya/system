# بطاقة الولاء — ضيافة القهوة الملكية (v6)

النسخة تحتوي على واجهة Cloudflare Pages، خدمات Supabase SQL، خدمة Edge `loyalty-push`، مراجع اختبار الكود، وشرح النشر. **الواجهة هي الملف ZIP المنفصل**؛ لا ترفع مجلد المصدر إلى Cloudflare مباشرة.

المستهدف: واجهة عميل بسيطة بالشعار البني والذهبي على أرضية فاتحة، 6 نقاط ومكافأة القهوتين، وتذكيرات دورية بالحجوزات بعد موافقة العميل. تجربة أول جهاز متلقٍ: كل 5 دقائق لمدة 30 دقيقة فقط، ثم الوضع الأسبوعي (الخميس 5 مساءً بتوقيت الرياض)، مع إمكانية إعادة الاختبار إداريًا لفترة قصيرة.

تم تطبيق migrations الخاصة بنظام التنبيهات على مشروع Supabase `qkretlvladsfnecnqyca` بالفعل، ونُشرت Edge Function للجدولة. لا تنسخ SQL من الملفات لتطبيقه مرة ثانية دون مراجعة الحالة الحالية.

لم يُختبر عرض إشعار على هاتف المستخدم بعد؛ يحتاج العميل رفع ملفات الواجهة على Cloudflare والتفاعل مع نافذة الإذن بعد فتح البطاقة المثبتة.
